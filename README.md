# Небесный разведчик

Живая карта неба для iPhone — лучше, чем Night Sky 2. Наводишь телефон на небо и видишь,
где **прямо сейчас** находятся спутники, планеты, Солнце и Луна, яркие звёзды и созвездия.

- **Три режима**: датчики (карта поворачивается за телефоном), AR поверх камеры, ручной (крутить пальцем).
- **Солнце, Луна с фазой и все планеты** — в реальном времени; объекты под горизонтом видны приглушённо.
- **Спутники**: МКС, Хаббл, Тяньгун, Starlink и другие яркие — живое движение, траектория пролёта,
  освещён или в тени Земли, ближайшие видимые пролёты.
- **Звёзды до 6-й величины и созвездия** с русскими названиями.
- **Карточка объекта** по нажатию: высота, азимут, восход и заход, расстояние.
- **Шкала времени**: листать вперёд и назад, кнопка «Сейчас».
- Красный ночной режим, работа без интернета, установка на экран «Домой».

Подробное техзадание и план этапов — в [ЗАДАЧА.md](ЗАДАЧА.md).

## Как открыть
Приложение — статический сайт, публикуется через GitHub Pages (Settings → Pages → ветка `main`, папка `/`).
На iPhone датчики и камера работают только по HTTPS — GitHub Pages это обеспечивает.
Дальше: «Поделиться» → «На экран «Домой»», и приложение запускается во весь экран.

## Устройство
Чистый фронтенд без сборки: `index.html`, ES-модули в `js/`, данные в `data/`.

| Что | Где |
|---|---|
| Карта неба: камера, проекция, датчики, отрисовка, интерфейс | `js/sky/` |
| Спутники: загрузка TLE, кэш, расчёт положения и пролётов | `js/satellites.js`, `vendor/satellite.js` |
| Солнце, Луна, планеты | `vendor/astronomy.js` (astronomy-engine) |
| Звёзды и созвездия | `data/stars.json`, `data/constellations.json` (собираются `tools/build-catalog.mjs`) |
| Магнитное склонение (компас → истинный север) | `js/sky/geomag.js` |
| Заготовки следующих этапов: погода, ночи, вердикт, засветка | `js/weather.js`, `js/nights.js`, `js/verdict.js`, `js/lightpollution.js`, `verdict.html` |

Орбиты спутников берутся с CelesTrak прямо из браузера и хранятся на телефоне
(обновляются не чаще раза в 12 часов). Запасной источник — копия в `data/tle/`,
её раз в сутки обновляет GitHub Action `.github/workflows/update-tle.yml`.

## Проверка
```sh
npm test                      # модульные тесты (node --test)
node tools/preview.mjs out/   # Chromium с эмуляцией iPhone: датчики, камера, спутники, скриншоты
```
