# Небесный разведчик

Веб-приложение для наблюдения за ночным небом с телефона.

Отвечает не на вопрос «что сейчас на небе», а на три практических:

1. **Стоит ли сегодня выходить?** — с учётом облачности, Луны и засветки
2. **Куда отъехать?** — ближайшие тёмные точки по карте светового загрязнения
3. **Как это снять?** — выдержка, ISO, интервал для таймлапса, время пролёта МКС

Плюс AR-режим: наводишь телефон на небо и видишь подписи планет, созвездий и спутников.

Подробное техзадание — в файле [ЗАДАЧА.md](ЗАДАЧА.md).

## Устройство

Чистый фронтенд без серверной части, публикуется через GitHub Pages.
Все данные из открытых источников, без платных API и ключей.
Интерфейс на русском, вёрстка под телефон, тёмная и «ночная» красная темы.

## Статус

Каркас. Разработка ведётся через облачные сессии Claude Code.
